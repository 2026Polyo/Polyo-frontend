원본 JPEG는 리사이즈·늘이기·재압축 없이 그대로 사용한다. 이전 PNG는 제거했다.
표시할 때 높이만 정하고 너비는 원본 비율을 따르게 해 정사각형으로 변형하지 않는다.

사진의 보랏빛 주 피사체 위치는 원본의 (67%, 39.5%)로 잡았다. 이를 화면의
(42%, 40%)에 고정하고 이미지 높이를 필드 높이의 160%로 표시한다.
필드 밖 부분만 잘라내며 PC·모바일·상점에서 같은 초점 기준을 사용한다.
게임 중 배치한 블록은 다른 배경과 마찬가지로 사진을 가릴 수 있다.

CSS로 별이나 성운을 생성하지 않는다. 원본에 이미 들어 있는 빛 번짐·촬영 궤적은
추가 효과나 해상도 확대로 만든 것이 아니다.
