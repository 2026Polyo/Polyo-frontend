# Minecraft 원본 음원

Java Edition 1.21.1의 원본 Ogg Vorbis 45개를 그대로 묶었다. 재인코딩·합성·노멀라이즈하지 않았다. 실행 시 외부 Minecraft 서버에 접속하지 않고 Vite가 배포하는 로컬 자산 하나를 읽는다.

- `originals.bin`: 12바이트 식별자 `POLYOMCA1\0\0\0` 다음에 원본 OGG가 순서대로 들어 있다.
- `bank.ts`: 원본 파일의 위치·길이와 37개 이벤트의 샘플 인덱스·볼륨·피치다.
- `provenance.json`: 원본 URL, 고정 소스 커밋, Git blob SHA-1과 SHA-256이다. 원본 권리는 Mojang AB에 있으며 미러 접근 가능 여부가 별도 사용 허가를 의미하지 않는다.
- `scripts/import-minecraft-audio.mjs`: 수동 재현용 가져오기 도구다. 기존 자산을 덮어쓰지 않는다. 빌드나 테스트에서 실행하지 않는다.

각 이벤트는 원본 정의의 앞 두 변형을 사용한다. 아이템 획득은 원본 파일이 하나이며 공통 파일은 중복 저장하지 않았다. 돌·금속·유리는 설치 파일을 공유한다. 금속은 높은 피치로 재생하고 유리는 파괴 시 유리 전용 음원을 사용한다.

선택 시 미리 로딩하며 디코딩 동시 작업을 4개로 제한한다. 읽기 실패 시 게임을 계속 진행하고, 캐시 실패 항목은 제거해 다음 로딩에서 재시도한다. 소리 선택·동시 재생·예약 취소는 각 플레이어에 속한다. 검사 코드는 원본 바이트·인덱스·캐시·오류 복구를 확인한다.
