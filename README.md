# Polyo-frontend
Polyo 프로젝트의 프론트엔드

React + TypeScript + Vite 기반이며, `npm run dev`로 실행합니다. `npm test`로 테스트하고 `npm run build`로 타입 검사와 배포 빌드를 수행합니다.

## 멀티

시작 화면의 **멀티**를 누르면 방 목록이 열립니다. 상단의 **코드로 접속**, **방 만들기**에서 코드 입장이나 방 생성을 할 수 있습니다. 공개 방은 목록에서 바로 입장하며 비공개 방은 코드로 접속합니다. 목록은 20개씩 조회하고 새로고침·이전/다음 페이지를 지원합니다.

- 목록: `GET /api/match-room?page=0&size=20`
- ID 입장: `POST /api/match-room/{roomId}/members`, 본문 없음
- 코드 입장: `POST /api/match-room/code/members`, JSON `{ entryCode }`. 앞뒤 공백 제거·대문자 변환 후 8자리 검사
- 생성: `POST /api/match-room`, JSON `{ roomName, isPrivate }`. 이름은 1~30자, 정원은 방장 포함 2명으로 고정되며 입력 항목에서 제외
- 생성·입장 성공 시 서버 발급 입장 코드를 표시하고 복사할 수 있습니다.
- 개발 연결: `.env.example`을 `.env.local`로 복사하고 `API_PROXY_TARGET`을 실행 중인 백엔드 주소로 설정한 후 Vite를 다시 시작합니다.
- 배포 연결: 기본은 동일 출처 `/api`입니다. 별도 API 서버를 사용하면 `VITE_API_BASE_URL`에 서버 출처를 설정해 빌드합니다. 서버는 해당 프론트 출처의 credential CORS 요청과 `Authorization` 헤더를 허용해야 합니다.
- 인증: 로그인 시 저장한 액세스 토큰을 `Authorization: Bearer` 헤더로 전달하고, 세션 쿠키도 `credentials: include`로 함께 전달합니다.

### 대전

방을 만든 뒤 **대기실 입장**, 또는 방에 접속한 뒤 **대전 입장**을 누르면 대전 화면(`MatchGameScreen`)으로 이동합니다. 두 명이 모두 접속하면 바로 시작합니다.

- 각자 자기 보드가 있고, 공용 블록 6개를 번갈아 하나씩 골라 자기 보드에 놓습니다. 6개를 다 쓰면 새 6개가 나옵니다. 블록마다 15% 확률로 특수 블록이 나옵니다.
- 한 수 제한시간은 하드모드와 같습니다. 10초에서 시작하고, 자기 점수가 100점 이상이면 한 수마다 0.1초, 200점 이상이면 0.2초씩 줄어 최소 2.8초까지 내려갑니다.
- 내 차례에 놓을 블록이 없거나, 시간이 초과되거나, 기권하면 패배합니다.
- 판정은 서버가 합니다. 클라이언트는 `/ws/match/{roomId}` WebSocket에 접속해 첫 메시지로 `{ type: "AUTH", token }`을 보내고, 이후 `PLACE`·`FORFEIT`를 보냅니다. 서버는 변경될 때마다 전체 상태(`STATE`)를 보냅니다.
- 연결이 끊기면 1초 뒤 다시 접속합니다. 끊긴 동안에도 시간은 흐릅니다.
- 개발 서버는 `/ws`도 백엔드로 프록시합니다.

블록은 누른 뒤 보드 칸을 눌러 놓습니다. 대전 화면에서는 끌어서 놓기를 지원하지 않습니다. 방 삭제와 대기 중 나가기 알림은 아직 구현되지 않았습니다.
