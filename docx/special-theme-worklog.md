# 특수 블록의 테마별 구분 — 2026-11-04

## 목표와 입력·출력

- 기존 일곱 특수 블록의 효과를 바꾸지 않고 외형으로 구분한다. 입력은 기존 특수 종류/색, 보드, 조각 uid와 위치다.
- 네온은 검은 내부의 일반 블록과 달리 특수 색으로 내부까지 밝게 채운다. 젤리는 두꺼운 색 윤곽선과 흰 안쪽 선, 종류에 따른 점선·이중선 등으로 구분한다. 필드·트레이·드래그·덱과 착지/제거용 모형에 공통 적용한다.
- 고양이는 고스트=은회색, 라인=치즈색, 에코=청회색, 황금=크림색, 폭탄=짙은 회색, 채움=삼색, 강화=갈색 줄무늬로 정했다. 일반 고양이는 흰색을 유지한다. 귀와 표정의 색도 털색에 맞춰 어두운 고양이에서 읽히게 한다. 기본·마인크래프트 외형은 변경하지 않는다.

## 조각별 연결과 저장

- 사용자 확인에 따라 같은 조각 내부의 특수 칸만 연결한다. 종류가 같아도 다른 uid의 특수 조각은 붙지 않으며 얼굴과 귀가 각각 생긴다. 일반 고양이와 특수 고양이도 연결하지 않는다.
- 보드의 색 문자열만으로 원래 조각을 구별할 수 없어 표시 전용 `specialPieceGroups`(좌표→조각 uid)를 추가했다. 모든 테마에서 배치 정보를 보관하므로 테마 전환에도 경계를 유지한다. 게임 점수·배치 가능 여부·특수 능력 판정은 이 정보를 읽지 않는다.
- 저장·불러오기·되돌리기 스냅샷에 함께 포함한다. 제거된 칸의 소유 정보는 정리하고, 고스트 겹치기와 채움으로 추가된 특수 칸은 새 조각에 배정한다. 중력 시뮬레이션의 기존 위치 추적을 프레임별로 노출해 표시 정보만 같은 경로로 옮긴다. 자동 되돌리기 시 지난 시각 효과도 초기화한다.
- 구형 저장에는 조각 uid 정보가 없으므로 정확한 원래 조각을 복원할 수 없다. 잘못 합치는 대신 기존 특수 칸을 각각 분리한다. 새로 배치한 조각부터 내부 연결과 저장을 유지한다. 입력 좌표·소유 uid를 정규화하여 잘못된 저장 정보나 남은 칸 정보는 버린다.
- 기존 게임 저장의 선택 필드 확장이며 DB·API에는 변경이 없다. 실제 서버 보드 연동 시 이와 동등한 조각 식별 자료의 전달 방법을 팀에서 정해야 한다.

## 완료 조건과 검증

- 191개 자동 테스트·타입 검사·빌드·공백 검사 통과.
- 새 검사에서 같은 종류의 별개 조각 분리, 일반 칸 병합, 고스트 덮어쓰기·채움 확장, 제거 후 정리, 구형/잘못된 저장, 매 중력 프레임의 위치와 uid 보존, 게임·되돌리기 저장 왕복을 확인했다.
- 브라우저에서 네온 내부 밝기/일반 블록 유지, 젤리 2~3px 윤곽선, 일곱 털색, 조각 내부 연결과 대칭적인 외부 경계, 얼굴 개수, 모바일 가로 넘침 없음, 오류 없음을 확인했다.
- 실제 게임에서 같은 종류의 특수 조각을 나란히 배치하고 새로고침 후 이어하기·되돌리기·중력 사용 후에도 경계와 uid가 유지되는지 확인했다.
- 기존 네온·젤리와 기본 테마의 동일 배치가 같은 21점·제거 결과를 유지했다. 기존 고양이 스퀴시·발바닥 소멸·상점 네 상품과 8×8 미리보기 회귀 검사도 통과했다.
- 비교 시연은 `http://127.0.0.1:5188/tmp/special-theme-preview.html`이며 시연·브라우저 검사·캡처는 Git 제외 경로 `tmp/special-check/`를 사용한다.

## 특수 고양이의 연속 털 패턴 개선

- 칸마다 다시 시작하던 백분율 줄무늬·큰 얼룩을 직접 그린 반복 SVG 털 패턴으로 교체했다. 줄무늬는 위아래 끝의 위치와 기울기가 일치하는 곡선을 사용하고, 얼룩은 반복 이미지 가장자리에서 끊기지 않게 배치했다. 무늬 불투명도와 테두리 대비를 낮추고 특수 칸 테두리를 1.25px로 조정했다.
- `CatTile`에 표시용 행·열 좌표를 전달한다. 필드는 CSS 컨테이너의 실제 너비와 간격으로, 트레이·드래그·덱은 기존 칸 크기 변수로 무늬 기준 좌표를 계산한다. 연결 시 확장되는 반 간격도 보정하고 border-box를 기준으로 칠해, 내부 경계의 투명 테두리 때문에 무늬가 어긋나지 않게 했다. 제거 스냅샷에도 같은 좌표를 사용한다.
- 반복 무늬는 필드에서 72px, 작은 조각에서 48px 주기다. 위치를 읽는 프레임별 JavaScript·ResizeObserver·새 타이머는 추가하지 않았다. 반응형 크기 변경에도 CSS 계산으로 연속 좌표를 유지한다. 조각 소유·저장·게임 규칙과 다른 테마에는 변경이 없다.
- 일곱 무늬 각각을 3·4·5·6·7·8·9·10칸 모양에서 검사했다. 연결된 타일의 화면상 배경 원점 차이가 0.1px 미만인지, L자와 2×5 조각 및 모바일에서도 같은지 확인했다.
- 테스트 191개·타입 검사·빌드 통과. 기존 조각별 경계·저장/이어하기·되돌리기·중력·발바닥 제거·상점 8×8 회귀 검사도 통과했다.
- 모양별 비교 시연: `http://127.0.0.1:5188/tmp/cat-pattern-preview.html`. 선택 메뉴에서 일곱 특수 무늬를 바꿔 볼 수 있다. 시연과 캡처는 기존 tmp 제외 경로에 둔다.
