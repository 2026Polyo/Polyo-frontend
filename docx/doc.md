# Polyomino 프로젝트 기능 정리

이 문서는 현재 코드 기준으로 정리한 `Polyomino Block Blast` 기능 설명서입니다. 기존 `README.md`는 인코딩이 깨진 부분이 많아 참고만 하고, 실제 구현은 `src/App.tsx`, `src/features`, `src/hooks`, `src/utils`, `src/components`, `src/constants`를 기준으로 확인했습니다.

## 1. 프로젝트 개요

- 장르: 8x8 보드에 폴리오미노 블록을 배치해 행/열을 지우는 블록 퍼즐 게임입니다.
- 기술 스택: React 19, TypeScript, Vite, Vitest, lucide-react, Web Audio API, localStorage.
- 기본 흐름: 시작 화면에서 새 게임/이어하기/덱 구성을 선택하고, 플레이 화면에서 3개의 블록 트레이를 사용해 보드에 배치합니다.
- 성장 요소: 점수 구간마다 증강을 선택하고, 일정한 증강 횟수마다 특수 블록 또는 잠긴 기본 블록을 보상으로 얻습니다.
- 보조 요소: 콤보 기반 아이템, 자동 되돌리기, 최고 점수, 진행 상황 자동 저장, 덱/보관함 시스템이 있습니다.

## 2. 화면과 전체 사용자 흐름

### 2.1 시작 화면

- `Polyomino` 제목과 장식용 블록 미리보기를 보여줍니다.
- 저장된 진행 상황이 있고 현재 트레이에 배치 가능한 블록이 있으면 `이어하기` 버튼을 표시합니다.
- `새 게임`은 현재 시작 덱 설정을 기준으로 보드, 점수, 증강, 아이템, 특수 마크를 초기화하고 플레이를 시작합니다.
- `덱 구성` 버튼으로 다음 게임에 가져갈 기본 블록과 특수 블록을 조정합니다.
- 최고 점수는 `Best` 배지로 표시합니다.

### 2.2 플레이 화면

- 중앙에는 8x8 보드가 있습니다.
- 보드 아래에는 항상 최대 3개의 트레이 블록 슬롯이 있습니다.
- 좌측에는 보유 증강 목록과 증강 상세 패널이 있습니다.
- 우측에는 아이템 슬롯 3개가 있습니다.
- 상단에는 현재 점수, 최고 점수, 선택한 블록을 배치했을 때 얻을 예상 점수가 표시됩니다.
- 설정 버튼으로 게임 재시작 또는 시작 화면 복귀를 할 수 있습니다.
- 별도 모달로 증강 선택, 특수/기본 블록 보상 선택, 보상 획득 확인, 현재 덱 보기, 리롤 선택, 게임 오버가 표시됩니다.

## 3. 보드와 기본 규칙

- 보드는 `SIZE = 8`인 8x8 격자입니다.
- 각 칸은 비어 있거나 색상/특수 색상 문자열을 가집니다.
- 일반 블록은 이미 채워진 칸과 겹칠 수 없습니다.
- 고스트 블록만 예외적으로 기존 블록 위에 겹쳐 배치할 수 있습니다.
- 배치 후 가로 행 또는 세로 열이 모두 차면 해당 줄이 제거됩니다.
- 행과 열이 동시에 완성되면 한 번의 배치로 여러 줄을 지울 수 있습니다.
- 줄 제거 직후에는 제거될 칸이 잠시 강조되고, `CLEAR_HIGHLIGHT_MS = 260ms` 뒤에 정리된 보드가 반영됩니다.
- 현재 트레이의 어떤 블록도 보드에 둘 수 없으면 게임 오버 후보 상태가 됩니다.
- 되돌리기 아이템과 되돌릴 스냅샷이 있으면 게임 오버 대신 자동 되돌리기를 먼저 사용합니다.

## 4. 블록 카탈로그와 덱

### 4.1 기본 블록 목록

게임에는 표준 블록과 잠금 해제형 추가 블록이 있습니다.

- 표준 폴리오미노: 정사각형, 가로/세로 4칸, L/J/S/Z/T 계열 회전형 블록이 기본 덱에 들어갑니다.
- 큰 블록: 3x3, 2x3, 3x2, 5칸 직선, V자형 등은 전체 카탈로그에는 있지만 기본 덱에는 포함되지 않습니다.
- 추가 특수형 기본 블록: 2/3/4칸 대각선, 반대 대각선, 3x4, 4x3, 4x4 같은 블록은 잠금 해제 대상입니다.
- 전체 카탈로그는 `PIECES`, 시작 기본 덱은 `DEFAULT_DECK`, 잠금 해제 대상은 `LOCKABLE_BLOCK_IDS`로 관리됩니다.

### 4.2 덱 구성 규칙

- 시작 덱의 기본 블록은 최대 20개까지 구성할 수 있습니다.
- 기본 블록 덱은 최소 1개 이상 남아야 합니다.
- 특수 블록 로드아웃은 최대 3개까지 다음 게임에 가져갈 수 있습니다.
- 특수 블록 보관함은 최대 24개까지 저장되며, 초과 시 오래된 항목이 밀려납니다.
- 같은 특수 블록 id는 보관함에 중복 저장하지 않습니다.
- 기본 블록 잠금 해제 목록, 기본 덱, 특수 보관함, 특수 로드아웃은 localStorage에 저장됩니다.
- 새 게임을 시작하면 현재 사용 가능한 기본 블록만 필터링해서 덱에 넣습니다.

### 4.3 트레이 생성

- 트레이는 항상 3칸입니다.
- 트레이가 모두 비면 새 트레이 3개를 생성합니다.
- 새 트레이는 가능한 한 현재 보드에서 3개를 모두 사용할 수 있도록 탐색합니다.
- 트레이 탐색은 동기 실행으로 오래 막히지 않도록 150ms 예산과 300회 랜덤 시도 제한을 둡니다.
- 탐색 실패 시 전체 덱을 대상으로 가능한 조합을 찾고, 그래도 실패하면 랜덤 트레이를 반환합니다.
- `콤보 보정` 증강이 있으면 작은 블록이 더 잘 나오도록 가중치를 줍니다.

## 5. 블록 선택과 배치 UX

- 트레이 블록을 클릭하면 해당 블록이 선택됩니다.
- 선택한 블록은 커서에 따라다니는 별도 미리보기 조각으로 표시됩니다.
- 블록 내부의 어느 칸을 잡았는지 `anchorCell`로 기억해 보드 위 배치 위치를 보정합니다.
- 보드 위에 마우스를 올리면 가장 가까운 유효 배치 위치를 찾습니다.
- 목표 위치와 실제 가능한 위치의 거리 제곱이 `MAX_SNAP_DISTANCE ** 2`보다 크면 잘못된 미리보기로 처리합니다.
- 유효한 경우 보드 위에는 배치될 칸이 하이라이트됩니다.
- 라인 블록은 제거될 행/열 전체를 미리 보여줍니다.
- 채우기 블록은 주변에 추가로 채워질 빈 칸도 미리 보여줍니다.
- 미리보기 점수는 랜덤성이 있는 확산 채우기/확산 제거를 제외하고 계산해 안정적인 값을 보여줍니다.
- 선택한 블록 외부를 누르면 선택이 해제됩니다.

## 6. 점수 시스템

### 6.1 기본 점수

- 배치 점수: 놓은 칸 수와 추가로 채운 칸 수를 기준으로 계산합니다.
- 줄 제거 점수: 제거한 줄 수당 기본 20점입니다.
- 멀티라인 점수: 한 번에 2줄 이상 지우면 추가 점수가 붙습니다.
- 콤보 점수: 현재 콤보와 제거 줄 수를 기준으로 추가 점수를 얻습니다.
- 올클리어 점수: 보드를 완전히 비우면 `올클리어` 증강 레벨에 따라 보너스를 얻습니다.
- 보드 압박 점수: 보드가 80% 이상 찬 상태에서 배치하면 `보드 압박` 증강 보너스를 받을 수 있습니다.

### 6.2 세부 계산 요소

- 배치 강화: `placement-score` 레벨당 배치 점수 배율이 10% 증가합니다.
- 칸 배치 보너스: `cell-placement-bonus` 레벨당 배치 칸마다 +1점입니다.
- 제거 강화: `clear-score` 레벨당 줄 제거 점수 배율이 10% 증가합니다.
- 칸 제거 보너스: `cell-clear-bonus` 레벨당 제거된 칸마다 +2점입니다.
- 균열 제거: 제거된 행/열에 인접한 블록 수에 따라 레벨당 +2점입니다.
- 과열: 줄을 지우지 못하고 둔 횟수만큼 다음 줄 제거 점수가 증가합니다.
- 콤보 가속: 현재 콤보가 높을수록 전체 점수 배율이 증가합니다.
- 아이템 연계: 아이템 사용 직후 다음 배치 점수 배율이 증가합니다.
- 강화 블록: 보드에 살아 있는 boost 칸 하나당 이번 점수에 5% 배율을 더합니다.

### 6.3 점수 표시

- 실제 점수는 즉시 상태에 반영됩니다.
- 화면의 점수 숫자는 50ms 간격으로 부드럽게 올라갑니다.
- 큰 점수 상승도 약 30틱 내에 끝나도록 증가폭을 자동 조절합니다.
- 선택 블록을 배치할 수 있을 때는 현재 점수 옆에 `+n` 예상 획득 점수를 표시합니다.

## 7. 콤보와 클리어 피드백

- 줄을 지울 때마다 지운 줄 수만큼 콤보가 증가합니다.
- 트레이 3개를 모두 사용했는데 그 트레이에서 한 번도 줄을 지우지 못했다면 콤보가 끊깁니다.
- `콤보 유지` 증강이 있으면 콤보가 끊길 상황에서 보유 충전량을 1 소모하고 콤보를 유지합니다.
- 콤보 유지 충전량은 줄을 지우면 해당 증강 레벨만큼 다시 찹니다.
- 한 번에 2줄을 지우면 `GOOD!`, 3줄은 `GREAT!`, 4줄 이상은 `EXCELLENT!` 라벨이 표시됩니다.
- 클리어 단계는 효과음 선택에도 같이 사용됩니다.
- 콤보 사운드는 줄 제거마다 1단계씩 올라가며 최대 8단계 사운드를 사용합니다.
- 콤보가 깨지는 트레이 완료 상황에서는 콤보 사운드 단계도 초기화됩니다.

## 8. 증강 시스템

### 8.1 증강 선택 조건

- 최초 증강은 50점 달성 시 열립니다.
- 이후 증강 목표 점수는 `직전 선택 점수 + 50 + 직전 선택 점수의 10%`입니다.
- `증강 할인` 레벨이 있으면 다음 목표 점수 간격이 레벨당 10%씩 줄어듭니다.
- 할인은 최대 90%까지만 적용됩니다.
- 목표 점수에 도달하면 3개의 증강 중 1개를 선택합니다.
- 리롤 강화만 최대 5레벨 제한이 있고, 나머지는 코드상 무한 레벨이 가능합니다.
- 총 증강 레벨이 3의 배수 구간을 넘을 때마다 일반 증강 대신 보상 선택이 열립니다.

### 8.2 증강 목록

#### 배치형

- `placement-score`: 블록 배치 점수를 레벨당 10% 올립니다.
- `cell-placement-bonus`: 배치한 칸 수에 비례해 레벨당 칸마다 +1점을 줍니다.
- `spread-fill`: 배치 후 일정 확률로 주변 빈 칸을 추가로 채웁니다. 레벨당 확률이 4% 증가하고, 3레벨마다 채우는 칸 수가 늘어납니다.
- `all-clear`: 보드가 완전히 비워질 때 레벨당 50점을 추가합니다.

#### 줄 제거형

- `clear-score`: 줄 제거 기본 점수를 레벨당 10% 올립니다.
- `cell-clear-bonus`: 제거된 칸마다 레벨당 +2점을 줍니다.
- `spread-clear`: 줄 제거 후 일정 확률로 인접한 줄도 추가 제거합니다. 레벨당 확률이 4% 증가하고, 3레벨마다 추가 제거 줄 수가 늘어납니다.
- `crack-clear`: 제거된 줄 주변에 붙어 있던 블록 수에 비례해 레벨당 +2점을 줍니다.

#### 콤보형

- `tray-combo`: 콤보 추가 점수를 강화합니다.
- `combo-accel`: 콤보 1당 전체 점수 배율을 레벨당 1%씩 올립니다.
- `combo-retain`: 트레이를 다 썼지만 줄을 못 지운 상황에서도 일정 횟수 콤보를 보존합니다.
- `combo-correction`: 트레이 생성 시 작은 블록이 나올 확률을 올려 콤보 유지가 쉬워지게 합니다. 레벨당 0.15씩, 최대 0.9 보정입니다.

#### 멀티라인/보드 상태형

- `multi-line`: 한 번에 여러 줄을 지울 때 추가 점수를 줍니다.
- `board-pressure`: 보드가 80% 이상 찬 상태에서 배치하면 레벨당 10점을 줍니다.
- `overheat`: 줄 제거 없이 배치한 횟수를 누적해 다음 줄 제거 점수를 올립니다.

#### 아이템형

- `reroll-power`: 리롤 아이템을 강화합니다. 1레벨은 1개 직접 선택, 2레벨은 2개, 3레벨은 3개, 4레벨은 후보 3개 중 선택, 5레벨은 덱 전체에서 직접 선택입니다.
- `item-discount`: 아이템 획득에 필요한 콤보 간격을 레벨당 2 줄입니다. 최소 간격은 2입니다.
- `item-gain-score`: 아이템을 획득해 슬롯에 실제로 들어갈 때 레벨당 20점을 줍니다.
- `item-use-score`: 아이템을 사용할 때 레벨당 15점을 줍니다.
- `item-chain`: 아이템 사용 직후 다음 배치 점수 배율을 레벨당 25% 올립니다.

#### 기타

- `augment-discount`: 다음 증강 선택에 필요한 점수 간격을 레벨당 10% 줄입니다.

### 8.3 증강 UI

- 보유한 증강만 좌측 패널에 표시됩니다.
- 각 증강은 아이콘 카드로 보이고, 마우스 오버 또는 포커스 시 상세 설명 패널이 열립니다.
- 상세 패널에는 아이콘, 이름, 레벨, 요약 설명이 표시됩니다.

## 9. 아이템 시스템

### 9.1 아이템 획득

- 아이템은 콤보가 특정 배수 구간을 넘을 때 획득합니다.
- 기본 획득 간격은 콤보 10입니다.
- `item-discount` 증강이 있으면 획득 간격이 줄고, 최소 2까지 내려갑니다.
- 아이템 슬롯은 3개입니다.
- 빈 슬롯에만 새 아이템이 들어갑니다.
- 슬롯이 꽉 찬 상태에서 추가 획득한 아이템은 버려집니다.
- 획득 아이템 종류는 되돌리기, 리롤, 중력 중 랜덤입니다.

### 9.2 되돌리기 아이템

- 직전 배치 전 스냅샷으로 되돌립니다.
- 되돌리는 항목은 보드, 점수, 트레이, 증강 상태, 고스트/골든/폭탄/강화 마크입니다.
- 줄 제거 애니메이션 중에는 사용할 수 없습니다.
- 사용 후 해당 슬롯이 비고, 저장된 되돌리기 스냅샷은 제거됩니다.
- 게임 오버 상황에서 되돌리기 아이템과 스냅샷이 있으면 자동으로 사용됩니다.
- 자동 사용 시 별도 플래시 알림이 1.5초 표시됩니다.

### 9.3 리롤 아이템

- 리롤 강화가 없으면 비어 있지 않은 트레이 슬롯 1개를 랜덤으로 바꿉니다.
- 리롤 결과도 가능한 한 현재 보드에서 트레이를 완료할 수 있게 탐색합니다.
- 리롤 강화가 있으면 전용 모달이 열립니다.
- 강화 레벨에 따라 바꿀 슬롯 수와 교체 방식이 달라집니다.
- 랜덤 모드는 선택한 슬롯을 자동 교체합니다.
- 후보 모드는 슬롯마다 3개의 후보 블록 중 하나를 고릅니다.
- 덱 모드는 현재 덱 전체에서 교체 블록을 직접 고릅니다.
- 취소하면 아이템은 소비되지 않습니다.

### 9.4 중력 아이템

- 보드의 모든 블록이 한 칸씩 아래로 떨어지는 과정을 반복합니다.
- 가득 찬 행이 생기면 해당 행이 지워지고, 위 블록들이 계속 떨어집니다.
- 중력은 프레임 단위 애니메이션으로 표시되며 프레임 간격은 70ms입니다.
- 애니메이션 중에는 입력이 잠깁니다.
- 이동한 블록의 고스트/골든/폭탄/강화 마크는 최종 위치로 함께 이동합니다.
- 중간에 제거된 블록의 마크는 사라집니다.
- 움직임이나 제거가 전혀 없으면 아이템을 소비하지 않습니다.

## 10. 특수 블록과 보상

### 10.1 보상 선택 구조

- 증강 3회 선택마다 다음 선택 기회가 특수 보상 선택으로 바뀝니다.
- 보상 후보는 최대 3개입니다.
- 후보에는 아직 잠금 해제하지 않은 기본 블록과 특수 효과 블록이 섞일 수 있습니다.
- 잠긴 기본 블록을 선택하면 해당 기본 블록이 영구 잠금 해제되고 현재 덱에도 추가됩니다.
- 특수 효과 블록을 선택하면 현재 게임의 특수 덱에 추가되고, 다음 게임에서도 쓸 수 있도록 보관함에 저장됩니다.
- 선택 후에는 보상 획득 모달이 표시됩니다.
- 보상 선택도 증강 선택 기회를 사용한 것으로 처리되어 다음 증강 목표 점수가 갱신됩니다.

### 10.2 고스트 블록

- 일반 블록과 달리 이미 채워진 칸 위에 겹쳐 둘 수 있습니다.
- 겹친 칸은 고스트 마크로 저장됩니다.
- 나중에 해당 칸이 줄 제거로 사라지면 겹친 칸마다 20점 보너스를 얻습니다.
- 제거되지 않은 고스트 마크는 계속 남습니다.

### 10.3 라인 블록

- 배치된 라인 블록의 각 칸을 기준으로 해당 행과 열 전체를 즉시 제거합니다.
- 여러 칸으로 이루어진 라인 블록이면 여러 행/열이 한 번에 지워질 수 있습니다.
- 미리보기 단계에서도 제거될 행/열 전체를 표시합니다.

### 10.4 에코 블록

- 배치 전 보드에 이미 채워져 있던 칸 수를 셉니다.
- 채워진 칸 하나당 5점 보너스를 얻습니다.
- 보드가 많이 찬 상태일수록 가치가 커집니다.

### 10.5 골든 블록

- 골든 블록이 놓인 칸은 골든 마크로 저장됩니다.
- 골든 마크가 있는 칸이 줄 제거에 포함되면 해당 칸 몫의 제거 점수를 한 번 더 받습니다.
- 즉, 해당 칸은 제거 점수 기준으로 2배 효과를 냅니다.
- 제거되지 않은 골든 마크는 남습니다.

### 10.6 폭탄 블록

- 폭탄 칸은 보드에 남아 있다가 그 칸이 줄 제거에 포함될 때 폭발합니다.
- 폭발하면 해당 칸의 행과 열 전체를 비웁니다.
- 폭발로 다른 폭탄 칸이 제거되면 연쇄 폭발합니다.
- 폭발로 추가 제거된 칸 하나당 5점 보너스를 얻습니다.
- 폭발한 폭탄 마크는 제거됩니다.

### 10.7 채우기 블록

- 배치 후 블록에 상하좌우로 인접한 빈 칸을 모두 채웁니다.
- 대각선 칸은 채우지 않습니다.
- 채워진 칸도 배치 점수에 포함됩니다.
- 채우기 효과로 줄이 완성되면 즉시 줄 제거가 발생합니다.
- 미리보기에서도 추가로 채워질 칸과 제거될 줄을 보여줍니다.

### 10.8 강화 블록

- 강화 블록 칸이 보드에 남아 있는 동안 이후 배치 점수를 올립니다.
- 보드에 살아 있는 강화 칸 하나당 점수 배율이 5% 증가합니다.
- 강화 블록을 놓는 바로 그 배치에는 새 강화 칸의 배율이 적용되지 않습니다.
- 강화 칸이 줄 제거로 사라지면 그 배율도 사라집니다.

## 11. 저장, 이어하기, 최고 점수

- 진행 중 게임은 localStorage 키 `block-blast-current-game`에 자동 저장됩니다.
- 저장 항목은 보드, 점수, 트레이, 현재 덱, 특수 블록, 증강 상태, 아이템 슬롯, 되돌리기 스냅샷, 특수 마크, 특수 보상 횟수입니다.
- 저장 데이터가 깨졌거나 보드/트레이 형식이 맞지 않으면 불러오지 않습니다.
- 예전 저장 형식의 `undoItems`, `rerollItems`는 3칸 아이템 슬롯 구조로 마이그레이션합니다.
- 최고 점수는 `block-blast-best`에 저장합니다.
- 현재 점수가 최고 점수를 넘으면 즉시 최고 점수를 갱신합니다.
- 시작 화면에서 저장된 게임이 있고 이동 가능하면 이어하기를 제공합니다.

## 12. 오디오와 시각 효과

- Web Audio API로 사운드를 미리 디코딩합니다.
- 브라우저 자동 재생 제한 때문에 사용자 입력 시 AudioContext를 resume합니다.
- 블록 배치음, 버튼 팝음, 팝업음, 게임 오버음이 있습니다.
- 2줄 이상 제거 시 good/great/excellent 효과음 중 하나를 재생합니다.
- 줄 제거가 있으면 콤보 단계별 사운드를 재생합니다.
- 증강 선택, 특수 선택, 보상 모달이 열릴 때 팝업 사운드가 납니다.
- 콤보 버스트와 클리어 라벨 버스트가 보드 위에 표시됩니다.
- 자동 되돌리기 발동 시 큰 되돌리기 아이콘과 메시지가 화면에 뜹니다.

## 13. 모달과 보조 UI

- `AugmentChoiceModal`: 증강 3개 중 하나를 고르는 화면입니다.
- `SpecialChoiceModal`: 특수 블록 또는 잠금 해제 블록 보상 3개 중 하나를 고르는 화면입니다.
- `BlockRewardModal`: 획득한 블록을 확인하는 화면입니다.
- `DeckModal`: 현재 게임에서 사용 중인 덱을 보여줍니다.
- `StartDeckModal`: 시작 화면에서 다음 게임용 덱과 특수 로드아웃을 편집합니다.
- `RerollModal`: 강화된 리롤 아이템의 슬롯 선택/교체 후보 선택을 처리합니다.
- `GameOver`: 최종 점수, 최고 점수, 재시작, 홈 이동을 제공합니다.
- `GameSettingsMenu`: 플레이 중 재시작 또는 홈 이동을 제공합니다.
- `ItemSlots`: 아이템 3칸과 사용 가능 여부를 표시합니다.
- `PieceShape`, `PiecePreview`, `PieceTray`, `Board`, `ScoreBoard`는 기본 게임 화면 구성 요소입니다.

## 15. 코드 기준 주요 파일

- `src/App.tsx`: 전체 게임 상태, 화면 전환, 배치 처리, 저장, 모달 제어의 중심입니다.
- `src/constants/gameData.ts`: 보드 크기, 전체 블록 카탈로그, 기본 덱, 색상 클래스, 잠금 해제 대상 블록을 정의합니다.
- `src/constants/config.ts`: 스냅 거리, 클리어 강조 시간, 저장 키를 정의합니다.
- `src/features/augments.ts`: 증강 목록, 레벨, 목표 점수, 점수 계산, 콤보 상태 갱신을 담당합니다.
- `src/features/items.ts`: 아이템 획득, 사용, 되돌리기, 리롤, 중력 애니메이션을 담당합니다.
- `src/features/resolvePlacement.ts`: 한 번의 배치 결과를 순수 함수로 계산합니다.
- `src/features/specials.ts`: 특수 블록 레지스트리, 라벨, 설명, 보상 후보 생성을 담당합니다.
- `src/features/specialStash.ts`: 특수 블록 보관함, 로드아웃, 기본 덱, 잠금 해제 저장을 담당합니다.
- `src/features/savedGame.ts`: 진행 중 게임 저장/불러오기와 저장 데이터 검증을 담당합니다.
- `src/features/*Blocks.ts`: 고스트, 라인, 에코, 골든, 폭탄, 채우기, 강화 블록 효과를 각각 구현합니다.

- `src/hooks/useGameAudio.ts`: 사운드 디코딩과 재생을 담당합니다.
- `src/hooks/useBestScore.ts`: 최고 점수 저장을 담당합니다.
- `src/utils/tray.ts`: 새 트레이 생성, 리롤, 덱 후보 생성, 트레이 완주 가능성 탐색을 담당합니다.
- `src/utils/placement.ts`: 배치 가능성, 배치 실행, 주변 빈 칸, 가장 가까운 배치 계산을 담당합니다.
- `src/utils/boardUtils.ts`: 보드 복제, 줄 제거, 중력 시뮬레이션, 확산 제거 보조 계산을 담당합니다.
