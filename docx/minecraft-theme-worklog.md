# 마인크래프트 테마 구현 기록

작성일: 2026-10-29

## 목표와 범위

- 사용자가 승인한 색상별 18종 블록을 `theme_minecraft`에 연결한다. 하나의 퍼즐 블록 안에서는 같은 재질만 반복한다.
- 배치는 간단하게 착지한다. 제거는 원래 블록 위의 채굴 균열 → 아이템화된 작은 3D 블록의 회전·부유 → 흰 소멸 입자 순서다.
- 기존 React·TypeScript·Vite 구조와 플레이어별 `ThemeScope`, 공통 `BoardFeedback`을 재사용한다. 실제 배치 좌표·점수·게임 판정·저장 형식·서버 API·구매와 재화 차감은 변경하지 않는다.
- 사운드는 다른 신규 테마와 같이 `pending`으로 남긴다. 임시 상점 가격도 네온·젤리와 같은 1,200코인이다.

## 입력과 출력

- 입력: 확정된 테마 ID, 각 칸의 기존 색상 키, 성공한 배치에서 생성한 제거 좌표·색상·이벤트 ID.
- 출력: 보드·트레이·드래그·덱·상점의 동일한 블록 재질과 시각 효과. 테마에서 게임 결과를 다시 계산하지 않는다.
- 시작 화면과 상점 상세에서 선택하고, 새로고침 후에도 기존 미리보기 설정으로 선택을 기억한다.

## 구현

- `minecraftMaterials.ts`: 18종의 재질·색상·옆면·윗면·아랫면과 채굴·소멸 프레임을 관리한다. 모르는 색상과 프로토타입 이름은 안전하게 다이아몬드로 대체한다.
- `MinecraftTile.tsx`: 보드·미니 블록·상점이 같은 텍스처를 사용한다. 진홍빛 네더 균사는 평면 보드에서 붉은 윗면을 보여준다.
- `MinecraftItemCube.tsx`: 여섯 면을 가진 CSS 3D 큐브다. 옆면·윗면·아랫면은 해당 블록의 실제 이미지이며, TNT와 네더 균사의 서로 다른 면도 유지한다. 평면 아이콘을 돌리는 방식은 사용하지 않는다.
- `minecraftFeedback.ts`: 제거 당시 색상과 각 아이템의 시작 각도·약간의 시차·다섯 개의 흰 입자를 한 번 생성한다. 게임의 `Math.random`을 소비하지 않는다.
- `MinecraftBoardEffects.tsx`: 제거 묶음만 보관해 새 일반 배치가 회전 중인 아이템을 끊지 않게 한다. 프레임별 상태 갱신이나 DOM 측정 없이 CSS가 균열·부유·회전·입자 프레임을 실행한다.
- `MinecraftTheme.css`: 마인크래프트 분위기의 짙은 필드, 각진 칸, 픽셀 텍스처, 단순 착지, 채굴·3D·흰 입자를 구현한다. 게임의 기본 보드 크기와 간격은 유지한다.
- 시작 화면·상점·공통 테마 정의에 ID와 설명을 연결한다. 실제 게임과 시연에서 같은 컴포넌트를 사용한다.

## 효과 순서와 관리

- 채굴 균열 열 단계를 약 360ms 동안 원래 블록 위에 표시한다.
- 좌상단부터 행 순서로 최대 360ms의 시차를 두고 작은 큐브로 전환한다. 각 큐브는 1~1.36초 동안 부유하며 Y축으로 회전한다.
- 모든 큐브는 1,640ms부터 함께 희미해져 1,720ms에 사라진다. 실제 `poof`의 흰 픽셀 입자도 동시에 8프레임을 재생하며 1,960ms에 종료한다. 묶음은 2,120ms 뒤 해제한다.
- 실제 게임의 260ms 제거 정리는 유지한다. 시각 효과만 제거 전 재질을 보관해 끝까지 보여준다.
- 동시에 최대 두 제거 묶음이다. 보드 전체가 두 번 연속 제거된 최악 조건에서도 128개 큐브·768개 면·640개 흰 입자로 제한된다. 가장 오래된 묶음은 타이머와 함께 제거한다.
- 초기화·언마운트·동작 줄이기에서 효과와 타이머를 해제한다. 동작 줄이기는 새 착지·3D 회전·입자를 생략하며 기본 제거 표시만 유지한다.
- 특수 블록의 제거 범위에 포함된 빈 칸은 공통 피드백에서 제외한다. 존재하지 않았던 블록이나 아이템이 나타나는 것을 방지하며, 점수와 제거 결과에는 관여하지 않는다.
- 효과 영역은 포인터를 가로채지 않고 필드 밖 파편은 잘라 모바일 가로 넘침을 방지한다.

## 이미지 관리

- 18종의 정면과 필요한 윗면·아랫면, 실제 채굴 균열 10장, 실제 흰 입자 8장을 로컬에 포함한다. 총 PNG 40장, 16,822바이트다.
- 블록 면은 Block Render의 평면 렌더링, 입자는 Minecraft Java Edition 1.21.1 원본 참고 파일을 사용한다. 원래 `poof.json`의 7 → 0 프레임 순서를 유지한다.
- 원본 아트의 저작권은 Mojang AB에 있다. 출처 URL·이미지 크기·바이트 수·SHA-256과 원래 프레임 순서를 `asset/theme/minecraft/provenance.json`과 README에 기록했다. 새 라이선스를 부여받았다고 표시하지 않는다.
- 게임 실행 중 외부 사이트에서 이미지를 가져오지 않으며, 테마 선택 시 작은 로컬 프레임을 미리 읽어 첫 채굴의 빈 프레임을 예방한다. 이미지가 누락돼도 재질별 바탕색으로 블록 영역은 유지한다.

## 검증

- 전체 자동 검사 174개(15개 파일), 타입 검사와 배포 빌드 통과.
- 18색 대응표의 중복 없음, 각 블록 면, TNT의 서로 다른 면, 테마 격리, 빈 칸 제외, 이벤트 데이터 보존, 난수 분리와 시각 수명을 자동 검사했다.
- 실제 브라우저에서 균열 단계 변화 → 여섯 면의 `preserve-3d` 큐브와 시간에 따른 `matrix3d` 회전 → 흰 입자의 교체·소멸을 확인했다.
- 단순 배치에 제거 아이템이 나타나지 않는 것, 새 배치가 기존 회전을 끊지 않는 것, 초기화와 수명 종료 후 정리, 보드 전체 연속 제거 상한을 확인했다.
- 모바일 가로 넘침 없음, 동작 줄이기, 상점에서 새 게임으로 선택 전달, 새로고침 후 선택 유지, 실제 트레이 재질을 확인했다. 실행 중 외부 이미지 요청도 없다.
- 실제 게임에서 기본 테마와 같은 배치가 동일한 21점과 같은 제거 보드를 유지했다. 저장 유지·잘못된 배치 차단·홈 왕복·이어하기 시 효과 재생 방지·미제공 음원의 무음도 통과했다. 기존 네온 효과와 젤리의 착지·가로/세로 스퀴시도 재검증했다.
- 시연 주소: `http://127.0.0.1:5188/tmp/minecraft-preview.html`. `tmp/` 시연·검사·캡처는 기존 Git 제외 경로다.

## 추후 연결

- 팀에서 준비한 테마별 배치·채굴·소멸 사운드를 기존 사운드 정의에 연결한다.
- 실제 보유 테마·구매·장착 API가 준비되면 기존 미리보기 선택과 분리해서 연결한다.
- 경쟁 모드에서는 플레이어마다 기존 `ThemeScope`를 제공해 서로 다른 외형과 효과를 유지한다.

## 흰 배경·인벤토리 필드·외곽선·순차 제거 개선

- 원본 인벤토리 참고 이미지: `https://raw.githubusercontent.com/InventivetalentDev/minecraft-assets/1.21.1/assets/minecraft/textures/gui/container/inventory.png`. 256×256 이미지를 조사하고, 회색 패널(#c6c6c6), 파인 회색 슬롯(#8b8b8b), 밝은 윗/왼 테두리와 어두운 아래/오른 패널 경계, 반대 방향인 슬롯 경계를 CSS로 재현했다. 원본 화면 전체를 늘려 붙이지 않고 기존 8×8 배치 크기를 유지한다.
- 실제 게임과 미리보기 바탕을 흰색으로 바꾸고 읽기 쉽도록 글씨·패널 색을 조정했다. 회색 필드는 상점 썸네일에도 반영한다.
- 18종의 블록과 아이템 큐브 각 면에 재질별 색상 외곽선 1px을 추가했다. 안쪽 외곽선이므로 칸 크기와 배치 좌표는 변하지 않는다.
- 제거 좌표를 행·열 순서로 정리해 좌상단부터 진행한다. 간격은 최대 55ms이며, 보드 전체 제거에서도 총 시차가 360ms를 넘지 않는다. 마지막 큐브에도 최소 1초의 회전 시간을 확보한다.
- 큐브가 나타난 시간과 관계없이 소멸 시작·종료는 공통 시간표를 사용한다. 흰 입자의 무작위 시작 지연도 없애 모든 칸에서 동시에 재생·종료한다. 새 타이머나 프레임별 JavaScript 작업은 추가하지 않았다.
- 64칸에서 첫 시차 0ms·마지막 360ms, 같은 소멸 종료 1,720ms를 확인했다. 520ms에서 앞쪽은 이미 큐브이고 뒤쪽은 채굴 중인 것, 1,680ms에서 모든 큐브의 유효 불투명도 0.5, 1,721ms에 전부 소멸하고 흰 입자가 남아 있는 것을 브라우저에서 검증했다.
- 18색의 서로 다른 외곽선, 인벤토리 색상, 기존 PC 3px·모바일 2px 간격 유지, 흰 게임 배경, 가로 넘침 없음, 정상 배치·점수 21·저장·홈 복귀, 연속 제거 상한·정리·상점 연결·동작 줄이기를 재확인했다. 전체 174개 검사·타입 검사·빌드 통과.

## 외곽선 가시성 보완

- 기존 안쪽 1px 선이 원본 텍스처와 비슷한 색이라 묻히는 문제가 있었다. 필드·상점·채굴 중 타일에 재질 색 2px 프레임, 안쪽 어두운 구분선 1px, 바깥의 짙은 색 경계 1px을 사용한다.
- 작은 트레이·드래그 타일과 아이템 큐브는 색 프레임 1px과 얇은 어두운 구분선으로 무늬를 남긴다. 실제 칸 크기와 배치 좌표는 유지한다.
- PC·모바일 캡처에서 테두리를 확인했고, 필드 색 프레임 2px·작은 타일 1px과 모바일 가로 넘침 없음을 검사했다. 배포 빌드 통과.

## 2026-11-03 블록 텍스처 단순화

- 목표: 18색의 재질 구분과 색감은 유지하면서 원본 Minecraft 블록 면의 촘촘한 무늬를 직접 그린 단순 도형으로 교체한다. 원본을 축소·필터 처리하거나 픽셀을 복사하는 방식은 사용하지 않았다.
- `asset/theme/minecraft/crafted/`에 24×24 격자의 SVG 22장을 작성했다. 보석은 큰 결정 면, 벌집은 큰 두 칸, 판자는 세 줄의 나뭇결, 양털은 엇갈린 짜임, 마그마는 굵은 균열로 표현한다. TNT 문자는 작은 기하 무늬로 교체했다. 진홍색 균사와 폭발 블록은 측면·윗면·아랫면을 구분한다.
- 공통 재질 정의의 이미지 연결만 변경하여 필드·트레이·드래그·덱·상점·채굴 중 블록·제거 시 3D 큐브에 일관되게 적용한다. 기존 테두리·배치 및 제거 시간표·게임 규칙·저장·API에는 변경이 없다.
- 사용하지 않는 원본 블록 PNG 22장은 제거했다. 채굴 균열 10장과 흰 입자 8장은 기존 이미지를 유지하며, 출처 기록을 남은 외부 파일과 직접 작성한 SVG로 구분하고 해시를 갱신했다. 블록 이미지 교체가 다른 참고 이미지까지 교체한 것을 의미하지 않는다.
- 전체 174개 자동 테스트, 타입 검사, 배포 빌드 통과. 처음 테스트 실행은 도구의 임시 파일 이름 변경 권한 문제로 중단되어 정상 실행 환경에서 재검사했다. 화면 검사도 브라우저 실행 제한을 해결하고 로컬 서버를 다시 시작해 완료했다.
- 실제 브라우저에서 18종 표시, 6면 큐브 회전·균열·흰 입자·효과 정리·연속 효과 상한, 모바일 가로 넘침 없음, 동작 줄이기, 상점 선택 후 게임 전달·새로고침 유지, 외부 이미지 요청 없음을 확인했다.

## 다이아몬드·에메랄드 중앙 보석 제거

- 두 SVG에서 중앙 결정 도형만 제거하고 청록색·초록색 바탕과 가장자리 색은 유지했다. 공통 재질을 사용하는 필드·트레이·상점·3D 큐브에 함께 반영된다.
- 이미지 출처 목록의 파일 크기와 해시를 갱신했다. 배포 빌드로 이미지 연결을 확인했다.

## 원본 텍스처 복원

- 사용자 요청으로 단순화한 SVG 대신 이전 원본 블록 PNG 22장을 동일 출처에서 복원했다. 사용하지 않는 SVG 22장은 제거하고 출처 기록을 갱신했다.
- 공통 재질 연결을 복원해 필드·트레이·덱·상점·3D 큐브에 동일하게 적용한다. 색상 대응표·외곽선·제거 애니메이션은 유지한다.
