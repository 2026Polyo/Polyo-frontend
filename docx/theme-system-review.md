# 테마 시스템 팀 공유 전 검토 — 2026-11-04

## 검토 범위와 결론

현재 스프린트의 블록 테마 커스텀과 상점 미리보기 범위에서 팀원이 이어서 개발할 수 있는 구조다. 테마 정의·공통 타일·효과 계산·효과 표시·미리보기 저장·임시 상품 공급자가 구분돼 있다. 게임의 배치 판정·점수·제거 결과와 실제 게임 저장을 외형 변경에서 분리했다. 후속 작업 위치는 `src/features/themes/README.md`에 정리했다.

## 보완 사항

- 설명 메타데이터 조회가 상속 속성을 반환하지 않도록 수정했다. `__proto__`, `constructor`, `toString` 등 서버/저장소에서 들어올 수 있는 특수 ID는 대체 미리보기를 사용하며, 기존 테스트에 해당 입력을 추가했다.
- 고양이 팔레트의 키를 마인크래프트 재질 목록 대신 공통 게임 색상 목록에서 가져오도록 바꾸어 두 테마의 불필요한 의존성을 제거했다.
- 네온·젤리 효과에 마지막 처리한 피드백 ID를 유지해 동작 줄이기를 켰다 꺼도 이전/만료 효과가 다시 재생되지 않게 했다. 새 피드백은 정상 재생하며 초기화 때 네온 표시도 즉시 숨긴다.
- 고양이 효과의 언마운트 정리에 피드백 ID 초기화를 추가했다. 효과 타이머는 초기화·언마운트에서 해제하며 동시에 유지할 효과 수에 상한이 있다.

## 검증

- 전체 185개 자동 검사·타입 검사·배포 빌드·공백 검사 통과.
- 실제 게임에서 네온·젤리·마인크래프트와 기본 테마가 같은 배치로 동일한 21점과 같은 제거 보드를 유지했다. 테마 선택으로 게임 저장이 바뀌지 않는 것, 잘못된 배치에서 효과가 없는 것, 기본 음원 대체 재생 없음, 모바일·홈 왕복·이어하기를 확인했다.
- 네온·젤리의 동작 줄이기 토글 시 지난 효과 재생 없음, 이후 새 배치 정상 재생, 만료 후 토글과 초기화를 확인했다. 처음의 고정 40ms 대기 검사가 브라우저 이벤트 반영보다 빨라 실패해, 실제 표시 해제 대기와 충분한 이벤트 반영 시간으로 검사 도구를 수정했다.
- 고양이 얼굴/귀 교체 스퀴시, 변화 없는 덩어리의 표정 유지, 순차 발바닥 소멸·동시 효과 상한·정리·동작 줄이기를 확인했다.
- 상점 네 상품만 표시, 모든 카드·상세의 8×8 필드, 고양이 장식 표시 위치와 마인크래프트 PNG, 정렬·모바일·게임 미리보기 선택을 확인했다.
- Minecraft PNG 40개의 해시를 provenance와 대조했다. 임시 시연·검사 도구·캡처·배포 결과물·의존성 폴더는 기존 Git 제외 규칙을 유지한다.

## 후속 연결 범위

로그인·구매·보유 조회·계정 장착·DB·경쟁 모드 서버 동기화·테마별 실제 음원은 이번 구현에 포함되지 않는다. 구매 버튼은 비활성 상태이며 선택값은 미리보기 전용이다. 서버 테마 ID와 외형 키 대응은 API 연동 시 확정한다. 이미지의 출처와 사용 조건은 자산 README 및 provenance에서 관리한다. 이번 검토는 UI 코드와 동작 검증이며 외부 자산의 추가 이용 허가를 의미하지 않는다.
