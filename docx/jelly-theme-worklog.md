# 젤리 테마 구현 기록

작성일: 2026-10-29

## 목표와 범위

- `theme_jelly`(젤리 팝)를 기존 플레이어별 테마 구조에 추가한다.
- 확대된 블록이 한 덩어리로 내려앉고, 착지 시 물방울이 사방으로 퍼지게 한다.
- 제거할 줄에 참격이 먼저 지나가고, 원래 젤리가 조각으로 부서지게 한다.
- 외형·효과·미리보기만 수정한다. 게임 판정, 점수, 드래그 좌표, 제거 대기 시간(260ms), 저장 형식, 서버 API는 유지한다.
- 사운드는 기존 테마 규칙에 따라 `pending`과 빈 음원 설정으로 남긴다.

## 입력과 출력

- 입력: 성공한 배치의 `BoardFeedback`(배치·제거 좌표, 색, 이벤트 ID), 가까운 `ThemeScope`의 테마.
- 출력: 젤리 타일, 그룹 낙하, 물방울, 가로·세로 참격, 젤리 파편. 게임 상태를 다시 계산하지 않는다.
- 시작 화면의 테마 선택과 상점 상세 미리보기에서 선택할 수 있고, 기존 미리보기 저장 기능으로 선택을 기억한다.
- 젤리의 임시 가격은 네온과 같은 1,200코인으로 표시한다. 실제 구매·장착·DB 연결은 기존 상태를 유지한다.

## 구현

- `gameThemes.ts`: 젤리 팔레트, 효과 종류, 사운드 연결 자리를 추가한다. 기존 모든 일반·특수 블록 색을 지원한다.
- `jellyFeedback.ts`: 화면 전용 난수로 물방울·파편을 한 번 생성한다. 게임의 `Math.random`은 사용하지 않는다. 완성한 가로·세로 줄은 각각 한 번만 베며, 특수 제거는 남은 구간을 표시한다.
- `JellyBoardEffects.tsx`: 배치 모양의 실제 경계 안에 타일을 모아 함께 움직인다. 300ms 착지 뒤 320ms부터 참격을 표시하고, 390ms 이후 조각을 분산한다. 제거 전에는 온전한 원래 젤리가 보인다.
- `Board.tsx`: 젤리 외형만 별도 면으로 그려 착지 모형과 실제 타일의 중복 표시를 막는다. 기존 버튼과 입력 처리는 재사용한다.
- `JellyTheme.css`: 윤기 있는 둥근 블록, 밝은 필드, 눌림·복원, 물방울, 참격, 파편을 구현한다. 밝은 배경에서 읽히도록 게임 안내와 패널 글씨를 조정한다.
- `ThemePreview`, `StartScreen`, 상품 예시 데이터: 상점과 실제 플레이에서 같은 젤리를 선택할 수 있게 연결한다.

## 예외와 효과 관리

- 실패한 배치는 기존 게임 계층에서 차단하므로 효과를 만들지 않는다.
- 중복·범위 밖 좌표는 공통 좌표 정리 함수를 재사용해 제외한다.
- 동시 효과는 최대 두 묶음이며 가장 오래된 묶음을 먼저 해제한다. 최악 입력인 한 묶음 64칸 배치와 64칸 제거에도 파티클은 512개, 두 묶음은 1,024개로 제한된다.
- 묶음은 1,200ms 뒤 해제한다. 초기화·언마운트·동작 줄이기 설정에서도 타이머와 효과를 정리한다.
- 프레임마다 난수 생성·상태 갱신·DOM 좌표 측정을 하지 않는다. 움직임은 CSS 애니메이션이 맡는다.
- 동작 줄이기에서는 낙하·파티클·참격을 생략하고 새 타일과 제거 결과를 보여준다.
- 효과 영역은 포인터 입력을 가로채지 않고, 필드 밖 파편을 잘라 모바일 가로 넘침을 방지한다.

## 검증 결과

- 전체 자동 검사 163개(14개 파일) 통과. 타입 검사와 배포 빌드 통과.
- 실제 게임에서 젤리와 기본 테마의 같은 배치가 같은 21점과 같은 제거 결과를 유지한다.
- PC 마우스와 모바일 터치로 L 블록을 끌어 놓아 네 타일이 한 덩어리로 착지하는 것을 확인했다. 트레이 26px → 드래그 72.125px(PC), 12.859px → 42.5px(모바일)로 기존 확대를 유지한다.
- 배치 타일당 물방울 7개, 제거 타일당 파편 4개를 확인했다. 원래 젤리 유지 → 참격 → 조각 분산 순서, 빠른 반복 상한, 초기화, 수명 종료 후 정리도 확인했다.
- 상대 기본 보드 격리, 잘못된 배치 무효, 저장 데이터 유지, 홈 왕복과 이어하기 시 효과 재생 방지, 음원 미제공 시 무음, 모바일 가로 넘침 없음, 동작 줄이기 설정을 확인했다.
- 상점 미리보기 선택 → 시작 화면 → 새 게임, 새로고침 후 선택 유지도 확인했다.
- 로컬 시연: `http://127.0.0.1:5188/tmp/jelly-preview.html`. `tmp/`의 시연과 브라우저 검사 파일·캡처는 기존 Git 제외 경로다.

## 발견한 문제와 해결

- 상품이 일곱 개가 되어 두 번째 페이지가 더 이상 빈 목록이 아니었다. 여섯 개를 전제로 한 기존 검사를 실제 `totalPages` 다음 페이지로 바꾸고, 전체 페이지의 누락·중복도 검사한다. 페이지 크기와 API 응답 형식은 바꾸지 않는다.
- 상점의 공통 배경 스타일이 젤리 배경보다 뒤에서 적용되어 바깥 여백이 파랗게 표시됐다. 젤리 선택자를 명확히 지정해 스타일 파일 순서에 의존하지 않도록 했다.
- 브라우저 드래그 검사에서 PC 트레이가 화면 아래에 있어 입력이 닿지 않았다. 검사에서 트레이를 화면 안으로 스크롤한 뒤 선택·이동하도록 보완했다. 게임 입력 코드는 변경하지 않았다.

## 추후 연결

- 팀에서 제공할 젤리 배치·제거 음원을 테마 사운드 정의에 연결한다.
- 서버 테마 ID가 확정되면 외형 정의와 연결한다. 현재 예시 상품 가격은 서버 값으로 대체한다.
- 경쟁 모드에서는 플레이어마다 `ThemeScope`를 두어 서로 다른 외형과 효과를 사용한다. 이번에는 경쟁 모드 자체를 추가하지 않는다.

## 젤리 질감·불규칙한 파편·참격 방향 개선

- 사용자 요청에 따라 블록의 외형과 제거 효과만 개선했다. 게임 판정·배치 좌표·점수·저장·사운드는 변경하지 않았다.
- 블록의 가장자리 색과 곡면 반사광, 아래쪽 굴절광을 겹쳐 속이 비치는 듯한 젤리 질감을 만든다. 조금 비대칭인 둥근 윤곽을 사용하고, 보드·트레이·드래그·상점이 같은 재질 정의를 재사용한다.
- 제거 파편의 고정 2×2 위치와 50% 정사각 크기를 없앴다. 큰 조각과 작은 조각의 가로·세로 크기, 시작 위치, 타원 곡률 여덟 값, 회전을 효과 시작 시 각각 생성한다. 비행 중에는 다른 곡률로 잠시 변형되어 부드럽게 흔들린다. 타일당 파편 수는 네 개를 유지한다.
- 원래 젤리는 참격이 지나가는 방향으로 최대 8px 밀린 뒤 파편으로 전환된다. 가로는 오른쪽, 세로는 아래쪽이며 교차점은 대각선 합력을 8px로 제한한다. 파편도 이 이동 위치에서 출발해 원래 젤리와 이어진다.
- 밀리는 움직임을 볼 수 있도록 시각적 파괴 시작을 390ms에서 440ms로 조정했다. 실제 게임의 260ms 제거 판정과 1,200ms 효과 수명은 유지한다.
- 동시 두 묶음과 파티클 상한은 동일하다. 윤곽 난수와 방향 계산은 묶음 생성 시 한 번만 수행하며 프레임별 JavaScript 작업은 추가하지 않는다.
- 자동 검사 165개 통과. 가로 (8px, 0), 세로 (0, 8px) 이동, 한 줄의 32개 파편이 서로 다른 윤곽과 크기를 갖는 것, 수명 종료 후 정리와 모바일 가로 넘침 없음을 브라우저에서 확인했다. 상점 선택·기존 착지·동작 줄이기도 통과했다.
- 시연 화면에 `세로 제거` 버튼을 추가해 두 방향을 비교할 수 있게 했다. 해당 시연 파일은 기존 `tmp/` 제외 경로에 둔다.

## 배치 전 블록의 외형 통일

- 트레이와 드래그를 그리는 `PieceShape`도 필드와 동일한 `jelly-tile-face`를 사용하도록 변경했다. 작은 블록용으로 따로 정의했던 재질과 반사광 선택자는 제거했다.
- 젤리 외형의 기준을 하나로 통일하고, 바깥 `mini-cell`은 기존 크기·좌표·선택 영역을 유지한다. 클릭은 장식 면이 가로채지 않는다.
- 시작 화면에도 선택한 테마 범위를 제공해 덱 구성에서 미리 보는 블록에 같은 젤리 외형을 적용한다.
- PC·모바일에서 배치 전 → 드래그 중 → 배치 후의 배경, 곡률, 그림자가 같은지 비교했다. 실제 드래그 좌표와 네 타일 배치, 효과 정리도 통과했다.
- 타입 검사, 전체 165개 자동 검사, 배포 빌드 통과.

## 배치 물방울 수 조정

- 사용자 요청으로 배치 타일당 물방울을 7개에서 4개로 줄였다. 네 칸 블록은 총 28개에서 16개가 된다.
- 360도 분산, 크기·속도 변화, 착지와 제거 효과는 유지한다. 최대 파티클 수 기록과 기존 수량 검사를 함께 갱신했다.
- 관련 자동 검사 9개, 타입 검사와 배포 빌드 통과.

## 착지·참격 스퀴시 추가

- 착지 그룹은 기존 낙하 궤적을 유지하고, 각 젤리 타일을 바닥 기준으로 가로 1.09·세로 0.84배 눌렀다가 0.96·1.07배로 반동을 준 뒤 원래 크기로 복원한다. 그룹 전체의 비균등 확대는 제거해 칸 간격까지 찌그러지지 않게 했다.
- 참격에는 온전한 젤리가 충격 방향으로 1.12배 늘어나고 수직 방향으로 0.88배 눌리는 효과를 추가했다. 약한 반동 후 원래 크기로 돌아가며 파편으로 이어진다. 가로·세로·교차 참격은 기존 충격 벡터의 각도를 사용한다.
- 젤리의 표시·숨김과 스퀴시는 서로 다른 CSS 애니메이션으로 실행한다. 방금 배치한 타일도 착지가 끝난 뒤 정상적으로 베이는 것을 확인했다.
- 착지 300ms, 참격 시작 320ms, 파괴 시작 440ms와 전체 효과 수명은 유지한다. 물방울은 타일당 네 개를 유지하고 게임 판정·점수·입력·사운드는 바꾸지 않는다. DOM·타이머·프레임별 JavaScript 작업도 추가하지 않았다.
- 브라우저에서 착지의 압축·반동·복원, 가로·세로의 방향별 변형, 새 타일의 정상 표시, 효과 정리, 상대 테마 격리, 모바일 가로 넘침 없음과 동작 줄이기 설정을 확인했다.
- 전체 자동 검사 165개, 타입 검사와 배포 빌드 통과.

## 블록 밀집감 조정

- 사용자 요청으로 온전한 젤리 타일의 모서리 곡률을 약 30%에서 14~16%로 줄였다. 비어 있는 필드 칸도 14%로 맞추고 윗면 반사광을 넓혀 서로 모여 있는 둥근 사각 젤리처럼 보이게 했다.
- 공통 외형을 수정해 필드·트레이·드래그·착지 모형·상점에 함께 반영한다. 실제 칸 간격·크기·배치 좌표와 불규칙한 제거 조각, 스퀴시는 유지한다.
- PC·모바일·상점 화면, 효과 순서와 정리, 상대 테마 격리, 동작 줄이기 및 배포 빌드를 확인했다.

## 유리 필드 시안

- 사용자 제안에 따라 젤리팝 필드를 연한 라벤더빛 반투명 유리판으로 바꿨다. 얇은 밝은 가장자리, 아래쪽 두께, 부드러운 그림자와 고정된 대각선 반사를 추가했다.
- 빈 칸의 불투명한 바탕을 줄이고 연한 보라색 경계와 흰 윗면 선으로 구분한다. 실제 보드와 상점 미리보기가 같은 유리 스타일을 사용한다.
- 반사광은 의사 요소 하나로 타일보다 아래에 배치하고 포인터 입력을 통과시킨다. 배경에만 고정 블러를 적용하며 애니메이션·타이머·DOM 노드는 추가하지 않았다. 블러를 지원하지 않아도 반투명 색과 반사·경계는 유지된다.
- 칸 크기·간격·배치 좌표·블록 재질·기존 효과는 유지한다. 젤리 테마 선택자에 한정해 기본·네온 필드에는 적용하지 않는다.
- PC·모바일·상점 표시, 3px 보드 간격 유지, 반사광의 입력 통과, 마우스·터치 드래그, 정상 배치·효과 정리, 상대 보드 격리·동작 줄이기 및 모바일 가로 넘침 없음을 확인했다. 배포 빌드 통과.

## 상품 설명 문구 조정

- 젤리팝 설명을 ‘손끝에 닿는 말랑함, 한 줄마다 터지는 즐거움. 반짝이는 유리 위에서 나만의 달콤한 플레이를 완성하세요.’로 변경했다.
- `themePresentation.ts`의 공통 설명만 수정해 상품 카드와 상세 모달에 함께 반영한다. 다른 테마·외형·게임 동작은 변경하지 않는다.

## 배치 물방울 단색화
