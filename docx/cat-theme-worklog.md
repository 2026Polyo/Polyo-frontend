# 고양이 드림 — 연결형 블록 구조

## 범위

- 고양이 그림과 포즈는 보류하고 `theme_cat`의 흰색 연결형 블록부터 구현한다. 고양이 이미지·소품·사운드·구매 API는 추가하지 않는다.
- 시작 화면의 테마 미리보기와 상점 미리보기에서 선택할 수 있다. 임시 상품 가격은 기존 구현 테마와 같은 1,200코인이다.

## 구현

- `catConnections.ts`는 상하좌우 점유 여부만 확인한다. 서로 다른 색·조각도 연결하며 대각선 접촉은 연결하지 않는다. 실제 보드의 색상과 특수 블록 값은 그대로 유지한다.
- `CatTile`을 필드·트레이·드래그·덱·상점에서 공통 사용한다. 연결된 방향으로 각 면을 기존 간격의 절반만큼 확장한다. 양쪽 흰 면이 만나므로 칸 사이와 2×2 중앙의 틈이 사라진다. 공유 윤곽선은 투명해지고 바깥 윤곽선은 연보라색으로 유지한다.
- 빈 필드에도 장식 면을 유지하여 새 배치 때 위치·윤곽선·모서리를 240ms 동안 전환한다. 블록 채움은 180ms 동안 나타난다. 별도 프레임 루프·타이머·보드 복제 상태는 추가하지 않았다.
- 제거가 시작되면 살아남는 칸은 제거 예정 이웃을 연결에서 제외한다. 틈이 다시 열리고 경계선이 나타난다. 제거 대상은 기존 260ms 게임 정리에 맞춰 희미해진다. 동작 줄이기 설정에서는 전환을 생략한다.
- 실제 필드와 트레이의 격자 간격·칸 크기·클릭 영역은 유지한다. 기존 테마는 장식 연결을 사용하지 않는다. 플레이어별 `ThemeScope`로 상대 기본 테마와 분리한다.
- 상점의 일반 칸 스타일이 중첩 장식 면에 적용되지 않도록 `.shop-preview-board > span`으로 직접 자식만 지정했다.

## 검증

- 177개 자동 검사 통과. 상하좌우·대각선 연결, 다른 색 사이 연결, 제거 후 노출 경계, 조각 내부 연결, 기존 테마 격리와 흰색 팔레트를 검사했다.
- 실제 브라우저에서 기존 오른쪽 면이 0px에서 -1.5px로 이동하고 윤곽선이 투명해지는 중간 상태를 확인했다. 연결 완료 시 양쪽 흰 면 사이의 좌표 차이는 0px이다.
- 제거 후 경계 복원·빈 칸 처리·64개 필드 유지, PC·모바일 가로 넘침 없음, 동작 줄이기, 상점 선택→시작 화면→새 게임, 새로고침 선택 유지, 실제 트레이 적용, 브라우저 오류 없음을 확인했다.
- 타입 검사·배포 빌드 통과. 미리보기는 `http://127.0.0.1:5188/tmp/cat-preview.html`, 검사·캡처는 Git 제외 경로인 `tmp/cat-check/`에 둔다.

## 추후 디자인

- 고양이를 넣을 위치와 표현 방식이 정해지면 공통 흰 면 위에 별도 장식으로 추가한다. 블록 연결과 점유 판정은 그대로 재사용한다.

## 표정·귀와 모양 변경 스퀴시

- 참고 이미지의 분위기를 멍함·졸림·장난기·울먹임·초롱초롱함의 다섯 표정으로 정리하고, 원본 그림을 삽입하는 대신 독립된 SVG 표정 도형을 작성했다. 흰 덩어리의 위쪽 양끝에는 흰 바깥 면과 연분홍 안쪽 면의 귀를 붙인다.
- `getCatRegions`가 상하좌우로 연결된 덩어리를 구하고 각 덩어리에 얼굴 하나와 귀 두 개를 배치한다. 무게 중심이 ㄱ자 안쪽이나 고리의 빈 공간에 놓이면 얼굴 전체가 흰 면 위에 들어가는 가까운 위치를 선택한다. 연결·분리에 따라 장식 개수도 바뀐다.
- 게임용 난수를 소비하지 않는 장식 전용 시드와 해시로 표정을 고른다. 같은 덩어리는 단순 재렌더나 호버로 표정이 바뀌지 않는다. 트레이·드래그의 같은 조각은 uid로 동일 표정을 유지한다. 플레이어별 장식은 별도 범위에서 관리한다.
- 점유 좌표 목록이 바뀐 덩어리는 이전 장식과 다음 장식을 잠시 함께 보관한다. 이전 얼굴·귀는 160ms 동안 눌렸다가 작아지며 퇴장하고, 다음 장식은 140ms 뒤 등장해 380ms 동안 납작해짐→늘어남→복원 순서로 튄다. 전체 520ms 뒤 이전 장식을 제거한다. 변하지 않은 덩어리의 장식은 다시 만들거나 움직이지 않는다.
- 애니메이션은 CSS의 transform·opacity로 실행하며 프레임별 JS는 없다. 장식 계층마다 정리 타이머 하나만 사용하고 언마운트·새 변경 시 이전 타이머를 취소한다. 빠른 연속 배치에서도 퇴장 묶음 한 세대와 새 묶음만 유지한다. 동작 줄이기 설정에서는 퇴장 잔상을 제거하고 즉시 교체한다.
- 장식은 포인터 입력을 가로채지 않는다. 기존 흰 면 연결·칸 좌표·색 데이터·게임 규칙·저장·API는 변경하지 않았다.
- 테스트 182개·타입 검사·빌드 통과. 덩어리별 얼굴/귀 수, 합침·분리, ㄱ자·고리의 빈 칸 회피, 64칸·중복 입력, 다섯 표정과 게임 난수 분리를 검사했다.
- 브라우저에서 60ms에 기존 얼굴만 보이며 가로 1.19배·세로 0.65배로 눌리는 것, 250ms에 기존 얼굴이 사라지고 다음 얼굴이 스퀴시 중인 것, 귀도 함께 전환되는 것을 확인했다. 변화 없는 덩어리의 DOM·표정 유지, 잔상 정리·제거·연속 배치·동작 줄이기·PC/모바일·상점 연결도 확인했다.

## 추가 표정과 발바닥 순차 제거

- 새 참고 이미지의 왕눈이·해맑은 웃음·이를 드러낸 웃음을 각각 `wonder`, `happy`, `grin`으로 직접 그려 총 8종으로 늘렸다. 기존 랜덤 선택·표정 유지와 모양 변경 스퀴시를 재사용한다.
- 고양이 테마 전용 `CatBoardEffects`와 `catFeedback.ts`로 시각 효과를 분리했다. 채워진 제거 칸만 스냅샷으로 보관하고 행·열 순서로 정렬한다. 기본 간격은 40ms이며 64칸 전체 제거에서도 마지막 시작은 280ms 이내다.
- 각 칸에서 분홍 발바닥이 내려앉아 가로로 퍼지고 세로로 눌린 뒤, 살짝 복원되었다가 작아지며 사라진다. 흰 블록 면도 함께 눌리며 소멸한다. 칸마다 같은 460ms를 사용하여 사라지는 순서도 좌상단부터 이어진다.
- 실제 게임의 260ms 정리는 변경하지 않는다. 그 뒤에도 제거 전 흰 면을 시각 계층에서 유지하여 후순위 칸이 먼저 사라지지 않게 한다. 애니메이션은 CSS만 사용하고 묶음당 한 타이머로 800ms 후 정리한다. 동시에 최대 두 묶음, 128개 발바닥으로 제한한다.
- 새 배치가 진행 중인 제거 효과를 끊지 않으며, 초기화·언마운트·동작 줄이기에서는 타이머와 잔상을 해제한다. 동작 줄이기는 발바닥을 생략하고 기존 흰 칸을 옅게 표시한다.
- 테스트 185개·타입 검사·빌드 통과. 브라우저에서 가로·세로 제거 순서, 180ms의 첫 발바닥 누름과 마지막 칸 유지, 500ms의 첫 칸 소멸과 후순위 발바닥 유지, 수명 종료·두 묶음 상한·초기화·모바일·동작 줄이기를 확인했다.
