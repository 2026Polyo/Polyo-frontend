# 보너스 타임 구현 기록

## 목표와 범위

일반모드에서 성공적으로 블록 60개를 배치하면 15초간 한 칸 블록만 제공한다. 하드모드는 기존 게임 규칙을 유지하고 보너스 타임을 제공하지 않는다. 점수, 증강, 특수 블록의 기존 처리 방식은 유지한다.

## 기술 및 참조

React + TypeScript + Vite. 기존 `src/hooks/useGameSession.ts`의 배치 검증/트레이 갱신과 `src/utils/tray.ts`의 생성 함수를 사용한다. 상태 전이 규칙은 `src/features/bonusTime.ts`, 저장은 `src/features/savedGame.ts`, 아이템 연동은 `src/hooks/useItemSystem.ts`에 연결했다. 시작 화면 및 플레이 화면에 모드 선택, 진행도, 남은 시간을 표시한다.

## 입력과 출력

- 새 게임 입력: 새 게임 버튼을 누르면 모드를 선택한다. 일반모드는 저장된 게임이 있을 때 “이전 게임을 이어가시겠습니까?” 안내를 표시한다. 예는 이어하기, 아니요는 새 게임, 취소는 홈 복귀다. 하드모드는 바로 새 게임을 시작한다. 별도 이어하기 버튼과 모드 설명은 표시하지 않는다.
- 배치 입력: 트레이에 존재하며 보드에 놓을 수 있는 블록을 성공적으로 배치했을 때 1개로 센다. 블록 내부 칸 수와 무관하다.
- 일반모드 출력: 60번째 배치 직후 트레이를 고유 ID를 가진 한 칸 블록 3개로 교체한다. 보너스 중 트레이 보충과 모든 리롤 단계에도 한 칸 블록만 제공한다.
- 종료 출력: 플레이 가능한 시간 15,000ms가 지나면 남은 보너스 블록을 제거하고 발동 직전의 일반 트레이로 복귀한다. 종료 시 선택 중인 블록도 해제한다.
- 반복 기준: 보너스 종료 후 다음 60개를 다시 센다. 보너스 중 배치는 다음 보너스의 진행도를 올리거나 시간을 연장하지 않는다.

## 예외와 상태 보존

- 잘못된 위치, 이미 사용한 블록, 배치 불가 상태 및 같은 처리 중 중복 호출은 배치 횟수를 증가시키지 않는다.
- 설정, 덱, 증강/특수 보상/리롤 선택창, 줄 제거/중력 연출, 홈 화면 및 게임 종료 상태에서는 시간을 멈춘다.
- 일반모드의 진행도, 남은 시간, 복귀할 트레이를 저장하여 이어하기를 지원한다. 하드모드는 저장/이어하기를 제공하지 않으며 기존 일반모드 저장을 덮어쓰거나 삭제하지 않는다. 새 일반모드 게임과 일반모드 게임 포기는 진행도를 초기화한다.
- 되돌리기는 배치 진행도와 트레이를 복원하지만 남은 시간을 늘리거나 종료된 보너스를 되살리지 않는다.
- 이전 저장 데이터는 일반모드/진행도 0으로 읽는다. 잘못된 횟수와 트레이는 초기화하고, 비정상적으로 긴 남은 시간은 15초로 제한한다.
- 네트워크를 사용하지 않는 로컬 기능이다. 저장 공간 오류는 기존 정책대로 플레이를 중단하지 않고 저장만 생략한다.

## 완료 조건 및 검증

`npm test`와 `npm run build` 통과. 보너스 관련 테스트 8개를 포함한 전체 113개 테스트 통과.

자동 검증: 59/60개 경계, 하드모드 120회 배치 시 미발동, 14,999/15,000ms 경계, 반복 진행도, 고유 한 칸 블록, 모든 리롤 생성 경로, 되돌리기 시간 제한, 이전/잘못된 저장 데이터, 저장 및 복원.

수동 확인 절차:
1. 일반모드로 시작해 유효한 블록 59개를 놓고 진행도 59/60 확인.
2. 60번째를 놓으면 한 칸 블록 3개와 보너스 표시가 나타나는지 확인.
3. 보너스 중 배치/리롤 후에도 한 칸 블록만 나오고, 15초 뒤 원래 트레이로 돌아오는지 확인.
4. 설정 또는 선택 창을 열었을 때 시간을 멈추고 닫은 후 남은 시간부터 진행하는지 확인.
5. 보너스 중 홈 이동 및 새로고침 후 이어하기로 남은 상태가 유지되는지 확인.
6. 하드모드에서 60개를 놓아도 발동하지 않는지 확인.

## 문제와 대응

기존 코드에 모드 구분과 보너스 진행도 저장이 없어 이를 추가했다. 발동 중 리롤이나 되돌리기로 다칸 블록이 나오거나 시간이 되살아나는 경우를 막도록 생성 풀 및 복원 규칙을 함께 연결했다. 보너스 화면은 25ms 간격으로 갱신하며 시간 갱신만으로 발생하는 저장은 초 단위로 제한했다.
